# Employee Collaboration

Choose the action that matches the missing information or ownership boundary.

- **Tool** records an external lookup or operation result as evidence.
- **Ask** requests clarification from a responsible participant.
- **Delegate** assigns a bounded child outcome to an eligible current-team agent.
- **Handoff** transfers a blocked responsibility to its proper owner with the known context.

Never Delegate to the 父链 or use delegation to return work to a parent. Report unknown information as 未知 and include the evidence gathered so far.
