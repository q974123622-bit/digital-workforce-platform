# 工作总结（work-summary）

本技能只基于事实生成总结，不补造工作内容。是否真的能查询工作记录、会话或任务，取决于当前 Runtime 提供的 Tool；权限判定仍由运行时统一治理链负责。

## 执行流程

1. 只使用有事实依据的工作记录；没有事实依据的内容不进入总结。

2. 区分状态：
   - 已完成；
   - 进行中；
   - 未完成；
   - 调研/复习；
   - 问题与解决。

3. 严禁：
   - 把计划写成完成；
   - 把复习写成开发成果；
   - 把未验证写成验证通过；
   - 把未提交写成已完成提交；
   - 根据目录名猜测工作内容。

4. 多条重复记录必须合并去重，不能重复统计同一项工作。

5. 信息不足时明确说明，不得补造不存在的开发、测试或提交结果。

6. 可以根据用户要求调整日报/周报格式，但不能改变事实状态。

7. 如果当前 Runtime 提供工作记录、会话或任务查询 Tool，可以调用；没有时，仅基于用户明确提供的内容工作。

   若环境中暴露正式工具名为 `query_work_records`，则使用它查询工作记录，可选参数为 status。

   若需要汇总工作记录并导出报表，且当前运行时暴露正式工具名为 `prepare_work_report`，则使用该 Workflow；若返回 approval_required，必须停止并提示审批。
