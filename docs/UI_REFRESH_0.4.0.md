# 0.4.0 UI 产品化优化说明

## 本次目标

本次优化以员工高频知识问答为主线，参考成熟协作产品的信息密度和交互秩序，不复制任何单一产品的品牌视觉。技术栈继续使用 React、Tailwind CSS 与 Ant Design，没有增加新的在线依赖。

## 已完成范围

- 登录页：从单张表单卡升级为企业产品入口，明确产品价值与安全边界。
- 员工端导航：统一图标、名称、选中态和移动端底部导航。
- 消息工作台：重做会话列表、聊天标题栏、长答案阅读宽度、消息气泡、输入区和空状态。
- 执行记录：保留可审计步骤与知识来源，避免展示隐藏推理、内部 Prompt 和敏感原文。
- 通讯录：改为响应式同事卡片，资料与发消息入口更明确。
- 插件中心：强化“已启用 / 可添加 / 我的提交”三种状态，补充插件用途说明与发布边界。
- 记忆管理：强化账号与数字员工隔离关系，并统一记忆状态、编辑和保留入口。
- 管理后台：统一标题层级、页面宽度、导航收起、卡片、表格和状态色。
- 响应式与无障碍：保留移动端单栏切换、44px 触控目标、键盘焦点和减少动效支持。

## 运行与二次修改

离线包已包含 `frontend/dist` 生产构建，首次执行 `./start.sh` 即显示新版界面。

修改 `source/frontend` 后，在离线包根目录执行：

```bash
./rebuild.sh frontend
```

脚本使用包内 `dwp-frontend-builder` 镜像离线构建，将最新静态文件同步到 `source/frontend/dist`，随后重新创建前端容器。

## 设计约束

- 品牌主色为 `#0969DA`，页面背景为 `#F5F7FA`。
- 主体使用白色表面、细边框和克制阴影；不使用大面积炫光、波纹或无业务含义渐变。
- 用户界面优先使用“运行环境、策略、知识来源”等业务语言，减少直接暴露底层工程术语。
- 后续新增页面应优先复用 `theme.ts`、`styles/tokens.css` 与 `index.css` 中的语义 Token。
