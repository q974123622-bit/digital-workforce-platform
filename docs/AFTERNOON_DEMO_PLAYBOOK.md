# 数字员工平台下午演示手册

适用版本：Sprint 13，AgentTeams + DeepSeek Harness + Policy/Gateway + Plugin Adapter。

建议演示时长：15-20 分钟。所有姓名、业务数据和 Adapter 回执均为虚构演示数据。

## 一、演示前准备

演示前 20 分钟在仓库根目录执行：

```powershell
# 推荐：重置演示数据，以干净状态启动真实 Harness
.\scripts\run_demo.ps1 -Docker
```

如果必须保留当前会话和任务：

```powershell
.\scripts\run_demo.ps1 -Docker -NoReset
```

检查：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
docker images dwp-dsh:rc6
```

打开 <http://localhost:5173>，按 `Ctrl+F5` 强制刷新。正式演示前，用一个不会在演示中复用的姓名完成一次入职冒烟测试。

## 二、推荐主线：15 分钟

### 1. 身份和策略差异（2 分钟）

目的：说明数字分身不是通用聊天机器人，权限随真实身份变化。

正式员工张三的数字分身输入：

```text
查询一下内部制度，并告诉我新员工如何申请 VPN
```

预期：内部知识检索允许，显示知识来源或正常回答。

切换到实习生身份后输入：

```text
查询一下内部制度，并告诉我新员工如何申请 VPN
```

预期：访问内部知识被拒绝，显示策略 ID 和拒绝原因。

讲解重点：同一问题因身份不同得到不同策略结果；Deny 发生在工具执行之前。

### 2. 闲聊与任务识别（1 分钟）

进入“新员工入职协作”群，先输入：

```text
大家下午好，今天辛苦各位了
```

预期：只出现一条成员回复，不创建任务卡。

讲解重点：群聊消息先做任务/闲聊判断，普通聊天不会误触发 Workflow 或 RPA。

### 3. 多员工入职协作和审批（7 分钟，核心）

使用一个未出现过的虚构姓名，例如：

```text
请帮新员工林平之办理入职，完成 HR 材料确认、IT 账号开通，并生成入职权限报表
```

观察顺序：

1. 用户消息发送后页面持续轮询，无需手动刷新。
2. 出现唯一 Task ID 和 `AgentTeams 团队协作` 来源。
3. AgentTeams 展示 Manager 受理、任务拆解、成员认领和协作结论。
4. VE-0002 HR 助理使用独立 DeepSeek Harness，上游工具显示“员工查询 MCP”。
5. VE-0003 IT 助理使用另一个独立 DeepSeek Harness，工具显示“入职流程 Workflow”。
6. RPA-0001 报表机器人进入 `pending_approval`，工具显示“报表机器人 · RPA”。
7. 点击“批准”，等待后台恢复执行。
8. RPA Adapter 返回后，Leader 和数字分身给出最终汇总。

预期界面：

| 角色 | 运行时 | 工具 | 状态 |
|---|---|---|---|
| VE-0002 HR 助理 | DeepSeek Harness | 员工查询 MCP | 已完成 |
| VE-0003 IT 助理 | DeepSeek Harness | 入职流程 Workflow | 已完成 |
| RPA-0001 报表机器人 | DeepSeek Harness | 报表机器人 · RPA | 先待审批，后完成 |

讲解重点：

- AgentTeams 负责协作，Harness 负责每个员工的任务理解和工具计划。
- Policy/Gateway 是唯一授权入口。
- Adapter 是 Harness 的工具，不是 Harness 的替代执行器。
- 审批通过只代表允许继续执行；必须收到 RPA 回执后才能显示完成。
- Harness 计划、员工回复和业务结果完整显示，不做用户可见文本截断。

### 4. 审计追踪（2 分钟）

入职任务完成后进入“审计中心”，用刚才的 Task ID 或 Trace ID 查询。

预期时间线：

```text
任务创建 > AgentTeams 协作 > HR/IT 执行 > RPA 待审批 > 人工批准 > RPA 执行 > 汇总
```

重点检查：执行员工、插件、allow/approval 决策、审批人和 Adapter 回执都能关联到同一 Trace。

### 5. 采购专业化角色（3 分钟）

新建群聊“研发采购协作”，添加 VE-0004 采购助理；也可以把 VE-0004 添加到已有测试群。输入：

```text
请采购助理为研发部申请 5 台 27 英寸测试显示器，预算 10000 元，完成需求澄清、三家比价和采购申请
```

预期：

- 任务指派给 VE-0004，不分给 HR、IT 或报表机器人。
- 运行时显示 DeepSeek Harness。
- 工具显示“采购申请 Workflow”。
- 因采购插件为 L3 敏感操作，进入人工审批。
- 批准后才执行采购 Adapter；拒绝则停止且不产生成功回执。

讲解重点：数字员工按岗位配置，不是所有机器人共享一套工具权限。

## 三、可选测试样例

以下样例任选 1-2 个演示即可。

### A. 审批拒绝分支

```text
请帮新员工任盈盈办理入职，完成 HR 材料确认、IT 账号开通，并生成入职权限报表
```

在报表环节点击“拒绝”。预期：HR 和 IT 保持已完成；RPA 和总任务进入 denied；不出现报表生成成功回执。

### B. 报销与周报并行

创建包含 VE-0002 和 RPA-0001 的群聊，输入：

```text
请整理张三本月差旅报销申请，并生成本周费用周报，分别说明当前状态和风险项
```

预期：VE-0002 调用差旅报销 Workflow，RPA-0001 调用周报 RPA，最后统一汇总两项结果。

### C. 会议纪要轻量任务

创建包含 VE-0001 的群聊，输入：

```text
请把上周架构部周会整理成结论、决议、行动项和遗留问题四个部分，并同步到共享盘
```

预期：调用会议纪要 Workflow，不触发敏感审批。

### D. 请假流程

创建包含 VE-0002 的群聊，输入：

```text
请帮张三申请明天下午半天年假，并同步直属领导审批和考勤记录
```

预期：调用请假审批 Workflow，展示申请、领导审批和考勤同步步骤。

### E. 重复任务和幂等

在 10 分钟内连续发送两次完全相同的入职指令。

预期：系统识别重复请求，复用或提示已有任务，不重复开通账号、不重复生成报表。

### F. Harness 降级

该场景建议放在演示最后，避免影响主线。

```powershell
.\scripts\run_demo.ps1 -NoReset
```

使用新姓名再次发送入职任务。预期 UI 明确显示“运行时：Demo Adapter 降级”，工具仍显示具体 MCP / Workflow / RPA 名称。测试后恢复：

```powershell
.\scripts\run_demo.ps1 -Docker -NoReset
```

## 四、现场讲解口径

建议始终使用下面四句话：

1. AgentTeams 负责“谁来做、如何协作”，不直接产生业务副作用。
2. 每个数字员工都有独立 Harness 上下文，Prompt 注入员工工号、人设、职责、Task ID 和协作结论。
3. Harness 负责理解和规划，Plugin Adapter 才负责真正调用 MCP、Workflow 或 RPA。
4. 所有动作先过 Policy/Gateway；审批、拒绝、工具回执和最终汇总都可审计。

真实与演示边界必须说明：AgentTeams 协作、策略状态机、Gateway、Harness 容器和审计链路属于系统实现；员工查询、入职、报表、采购等 Adapter 当前返回虚构演示数据。

## 五、现场异常处理

| 现象 | 处理 |
|---|---|
| 发送后暂时只有用户消息 | 等待持续轮询；不要连续点击发送；必要时 `Ctrl+F5` |
| 提示重复任务 | 换一个虚构姓名，或清空该会话后重试 |
| Harness 显示 Demo Adapter 降级 | 检查 Docker Desktop、镜像和 `-Docker` 启动参数 |
| AgentTeams 暂时无回复 | 继续等待任务卡；检查后端日志是否进入内置安全降级 |
| 审批后仍在处理中 | 等待后台 Harness 和 Adapter 返回，避免重复点击审批 |
| 主链路临时失败 | 使用已存在的种子任务讲任务卡、审批和审计；如实说明降级状态 |

## 六、演示通过标准

- 同一 Task ID 贯穿 AgentTeams、Harness、审批、Adapter 和汇总。
- 至少展示两个不同数字员工的独立 Harness 上下文。
- 至少展示 MCP、Workflow、RPA 三类工具。
- 至少展示一次 approval，并完成批准或拒绝分支。
- 页面发送后自动轮询，不依赖手动刷新。
- UI 同时区分运行时和工具，不出现笼统的 Adapter 执行器标签。
- 用户可见的 Harness 计划、员工回复和工具结果完整展示。
