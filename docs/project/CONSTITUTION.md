# AI员工平台项目宪法

> 版本：0.1.0
> 状态：草案，待项目成员评审后生效
> 起草日期：2026-08-31
> 适用对象：所有项目成员、Codex、GitHub Copilot及其他AI代理
> 权威性：本文件是项目工程治理原则的唯一真源

## 1. 适用范围与规范用语

本宪法规定AI员工平台长期不可违反的工程底线。功能需求归入OpenSpec，系统设计归入SDD或架构文档，操作步骤归入Runbook，不在本文件展开。

- **必须（MUST）**：不可违反；未满足时不得声称工作完成。
- **禁止（MUST NOT）**：任何人类或AI代理均不得执行。
- **应该（SHOULD）**：默认遵守；偏离时必须记录理由和影响。
- **可以（MAY）**：根据实际情况选择，不构成强制要求。

法律法规和公司制度高于本宪法；本宪法高于临时提示词、功能规格、实现计划和AI建议。

## 2. 核心原则

### 原则一：人类负责，AI受控

- AI可以在授权范围内分析、设计、编码和测试，但最终结果必须由人类确认。
- AI禁止自行修改本宪法、扩大需求、使用真实凭据、部署、删除数据或执行未经授权的外部写操作。
- AI不得作为第二名人类评审者；人类对合并、发布及业务影响承担最终责任。
- 测试环境允许实施者自审；高风险变更扩大范围或正式使用前，必须由另一名人类复核。

### 原则二：MVP控制复杂度，安全不可降级

- 项目必须以可验证的真实业务场景推动MVP，不得为未经验证的未来需求提前建设复杂平台能力。
- 新增模块、基础设施或依赖必须对应明确的当前需求，并说明成本和退出方式。
- 权限、数据、密钥、审计和真实/Mock隔离禁止以赶进度为理由降级。
- 可延期事项必须如实登记，禁止把未完成或演示能力描述为正式可用。

### 原则三：保护数据、密钥与环境边界

- 真实Secret、Token、密码和认证头禁止进入Git、代码、普通日志、Prompt、截图、测试样例或业务数据库。
- 凭据必须通过环境变量或公司批准的安全配置机制注入。
- 公司真实内部数据禁止保存到不可访问公司内网的外部本机；跨环境移动必须使用公司批准的方式。
- 内部资料仅可在公司批准的AI工具中按最小必要原则使用，能够脱敏或裁剪时禁止提供完整真实内容。

### 原则四：架构边界不得绕过

- 企业微信网关只负责消息渠道和身份映射，不得承载业务规则、知识检索或权限决策。
- 受控能力必须遵循 `Identity -> Policy -> Gateway -> Harness/Adapter -> Result -> Audit`。
- 知识访问必须遵循 `Identity -> Policy -> Gateway -> KnowledgeAdapter -> Knowledge Engine`。
- Policy Engine是唯一授权决策来源；业务模块、LLM、前端和渠道禁止直连内部知识库、数据库或企业系统。

### 原则五：OpenSpec按风险使用，禁止规范膨胀

- 涉及公共API、数据、权限、外部系统、跨模块或部署的变更，必须在编码前建立OpenSpec change。
- 不改变外部行为的单模块低风险修复可以直接开发，但仍须测试和记录。
- `propose`只负责目标、规格、设计和任务，`apply`才负责实施；两者不得混淆。
- 规格必须足以实施和验收，但禁止为形式完整而重复生成无决策价值的文档。

### 原则六：契约、测试与审计共同定义完成

- 公共API和共享数据契约变更必须保持兼容，或提供明确的版本、迁移和回滚方案。
- 开发时必须运行相关测试，合并或发布前必须通过适用的后端、前端、渠道、契约和安全检查。
- 权限拒绝、无结果、超时和依赖故障必须有可验证行为；测试禁止默认访问生产数据或产生外部副作用。
- 只有规格、测试、安全、审计、文档和回滚要求均满足，且遗留项已如实记录，变更才可标记完成。

### 原则七：真实失败，禁止Mock冒充

- 真实知识库、模型或关键依赖不可用时，受控测试和正式链路必须显式返回不可用状态并记录审计。
- 正式或真实数据链路禁止静默降级到Mock、演示数据或虚构答案。
- 仅明确标识的Demo模式允许降级，界面、日志和结果必须醒目标注。
- 超时、重试和错误处理必须有界，禁止无限等待、无限重试、重复副作用或泄露内部敏感信息。

### 原则八：发布可复现、可回滚，治理属于人类

- 每个部署版本必须能追溯到确定的Git提交；代码、配置和凭据必须分离。
- MVP可以人工部署，但必须使用固定发布物、健康检查、日志、备份责任和可执行回滚方案。
- 新变更自本宪法生效后立即遵守；现有缺口应登记并按风险逐步治理，不得继续扩大。
- 所有人类项目成员均可提出修订；修订至少需要一名人类成员明确批准，并记录版本、日期、理由和影响。
- AI禁止自行批准或生效宪法修订；修订后必须检查OpenSpec、AI指令和自动化门禁是否需要同步。

## 3. 生效

本宪法经至少一名人类项目成员明确确认后生效。在正式确认前，本文件保持草案状态并用于评审，不作为已完成合规的证明。
